# 表单配置-依赖关系

## 功能模块概述

表单字段依赖关系是指表单中一个字段的值或状态会影响另一个字段的显示、选项或行为。它是实现复杂表单逻辑的重要机制，能够提高表单的交互性和用户体验。

**主要用途**：

- 实现级联选择（如省市区选择）
- 根据前置字段的值动态显示或隐藏后续字段
- 根据前置字段的值动态加载后续字段的选项
- 实现复杂的业务逻辑验证

**应用场景**：

- 机构与部门的级联选择
- 产品分类与产品的级联选择
- 基于用户类型显示不同的表单字段
- 基于选择的业务类型显示不同的表单内容

## 核心实现原理

### 技术架构

表单字段依赖关系的实现主要基于以下技术架构：

1. **依赖配置**：通过字段的dependencies属性配置依赖关系
2. **响应式数据**：使用ref或reactive存储依赖数据
3. **触发机制**：当前置字段值变化时，触发依赖字段的更新
4. **动态加载**：对于需要从后端获取数据的依赖字段，实现动态数据加载

### 数据流程

1. 表单初始化时，加载所有字段的初始状态
2. 用户修改前置字段的值
3. 前置字段的值变化触发依赖字段的trigger函数
4. trigger函数更新依赖数据并可能清空依赖字段的值
5. 依赖字段根据新的依赖数据重新加载选项或更新状态
6. 依赖字段的显示或行为发生相应变化

## 标准实现步骤

### 前置条件

- 已了解项目中使用的表单组件类型
- 已确定需要实现依赖关系的字段对
- 已了解后端接口对依赖数据的提供方式

### 实现步骤

1. **定义依赖数据**：使用ref创建响应式数据存储依赖关系
2. **配置前置字段**：确保前置字段的配置正确
3. **配置依赖字段**：
   - 设置dependencies属性，指定triggerFields和trigger函数
   - 在componentProps中使用dependencies值
   - 对于ChcSelect组件，配置triggerFields和triggerFieldKeys
4. **实现trigger函数**：在trigger函数中更新依赖数据并处理相关逻辑
5. **测试依赖关系**：确保依赖关系正常工作

## 完整代码示例

### 基本依赖关系示例

```typescript
import { ref } from 'vue';

// 定义依赖数据
const deptIdDependencies = ref({ orgId: '' });

const formSchema = [
  // 前置字段：机构
  {
    component: 'ChcSelect',
    componentProps: () => {
      return {
        dictUrl: '/sys/org/pageOrgList',
        showSearch: true,
        placeholder: '请选择',
        allowClear: true,
        paginate: true,
        filterByFrontEnd: false,
        showChooseAll: '',
        immediate: true,
      };
    },
    defaultValue: '',
    fieldName: 'orgId',
    label: '机构',
  },

  // 依赖字段：部门
  {
    component: 'ChcSelect',
    componentProps: () => {
      return {
        onlySearchDataWhenDependencesChange: true,
        placeholder: '请选择',
        paginate: false,
        showChooseAll: '',
        dictUrl: 'sys/dept/deptList/{{orgId}}', // 数据接口地址，使用占位符
        showSearch: true,
        triggerFields: ['orgId'], // 触发字段
        triggerFieldKeys: {
          orgId: 'orgId', // 触发字段映射
        },
        filterByFrontEnd: true,
        dependencies: deptIdDependencies.value, // 依赖数据
        formatInterfaceData: (data: any) => {
          return { records: data };
        },
      };
    },
    dependencies: {
      triggerFields: ['orgId'], // 触发字段
      trigger(values: any) {
        // 更新依赖数据
        deptIdDependencies.value.orgId = values.orgId;
        // 清空依赖字段的值
        ChcGridApi.formApi?.setFieldValue?.('deptId', undefined);
      },
    },
    fieldName: 'deptId',
    label: '部门',
  },
];
```

### 复杂依赖关系示例

```typescript
import { ref } from 'vue';

// 定义依赖数据
const productDependencies = ref({ categoryId: '', brandId: '' });

const formSchema = [
  // 产品分类
  {
    component: 'ChcSelect',
    componentProps: () => {
      return {
        dictUrl: '/sys/product/categoryList',
        showSearch: true,
        placeholder: '请选择产品分类',
        allowClear: true,
      };
    },
    fieldName: 'categoryId',
    label: '产品分类',
  },

  // 品牌（依赖产品分类）
  {
    component: 'ChcSelect',
    componentProps: () => {
      return {
        dictUrl: '/sys/product/brandList/{{categoryId}}',
        showSearch: true,
        placeholder: '请选择品牌',
        allowClear: true,
        triggerFields: ['categoryId'],
        triggerFieldKeys: {
          categoryId: 'categoryId',
        },
        dependencies: productDependencies.value,
      };
    },
    dependencies: {
      triggerFields: ['categoryId'],
      trigger(values: any) {
        productDependencies.value.categoryId = values.categoryId;
        // 清空依赖字段的值
        formApi?.setFieldValue?.('brandId', undefined);
        formApi?.setFieldValue?.('productId', undefined);
      },
    },
    fieldName: 'brandId',
    label: '品牌',
  },

  // 产品（依赖品牌）
  {
    component: 'ChcSelect',
    componentProps: () => {
      return {
        dictUrl: '/sys/product/productList/{{categoryId}}/{{brandId}}',
        showSearch: true,
        placeholder: '请选择产品',
        allowClear: true,
        triggerFields: ['categoryId', 'brandId'],
        triggerFieldKeys: {
          categoryId: 'categoryId',
          brandId: 'brandId',
        },
        dependencies: productDependencies.value,
      };
    },
    dependencies: {
      triggerFields: ['brandId'],
      trigger(values: any) {
        productDependencies.value.brandId = values.brandId;
        // 清空依赖字段的值
        formApi?.setFieldValue?.('productId', undefined);
      },
    },
    fieldName: 'productId',
    label: '产品',
  },
];
```

### 基于值的字段显示/隐藏示例

```typescript
import { ref, computed } from 'vue';

// 定义依赖数据
const formValues = ref({ userType: '' });

// 计算字段显示状态
const showEmployeeFields = computed(() => {
  return formValues.value.userType === 'employee';
});

const showCustomerFields = computed(() => {
  return formValues.value.userType === 'customer';
});

const formSchema = [
  // 用户类型
  {
    component: 'Select',
    componentProps: {
      options: [
        { label: '员工', value: 'employee' },
        { label: '客户', value: 'customer' },
      ],
      placeholder: '请选择用户类型',
      onChange: (value: string) => {
        formValues.value.userType = value;
      },
    },
    fieldName: 'userType',
    label: '用户类型',
    required: true,
  },

  // 员工特有字段
  {
    component: 'Input',
    fieldName: 'employeeId',
    label: '员工ID',
    required: true,
    visible: showEmployeeFields,
  },

  // 客户特有字段
  {
    component: 'Input',
    fieldName: 'customerId',
    label: '客户ID',
    required: true,
    visible: showCustomerFields,
  },
];
```

## 组件/API说明

### 依赖关系配置属性

| 属性 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| dependencies | object | 依赖关系配置 | { triggerFields: ['orgId'], trigger: (values) => {} } |
| triggerFields | array | 触发字段数组 | ['orgId', 'categoryId'] |
| trigger | function | 触发函数 | (values) => { deptIdDependencies.value.orgId = values.orgId; } |
| componentProps.dependencies | object | 组件依赖数据 | deptIdDependencies.value |
| componentProps.triggerFields | array | 组件触发字段 | ['orgId'] |
| componentProps.triggerFieldKeys | object | 组件触发字段映射 | { orgId: 'orgId' } |
| componentProps.onlySearchDataWhenDependencesChange | boolean | 仅当依赖变化时搜索数据 | true |

### 常用组件的依赖关系支持

#### ChcSelect组件

ChcSelect组件是实现依赖关系的核心组件，它支持以下依赖关系相关的属性：

| 属性                                | 类型     | 描述                       |
| ----------------------------------- | -------- | -------------------------- |
| dictUrl                             | string   | 数据接口地址，可使用占位符 |
| triggerFields                       | array    | 触发字段数组               |
| triggerFieldKeys                    | object   | 触发字段映射               |
| dependencies                        | object   | 依赖数据                   |
| onlySearchDataWhenDependencesChange | boolean  | 仅当依赖变化时搜索数据     |
| formatInterfaceData                 | function | 数据格式化函数             |

#### 其他组件

对于其他组件，可以通过以下方式实现依赖关系：

1. **使用计算属性**：根据前置字段的值计算当前字段的属性
2. **使用watch**：监听前置字段的变化，更新当前字段的状态
3. **使用onChange**：在前置字段的onChange事件中更新依赖数据

## 常见问题与解决方案

### 问题1：依赖关系不生效

**解决方案**：

- 确保正确配置了dependencies属性
- 检查triggerFields是否包含正确的字段名
- 确保trigger函数正确更新了依赖数据
- 对于ChcSelect组件，确保配置了triggerFieldKeys

### 问题2：依赖字段的值没有清空

**解决方案**：

- 在trigger函数中使用formApi?.setFieldValue?.()清空依赖字段的值
- 确保trigger函数被正确调用

### 问题3：依赖字段的数据没有重新加载

**解决方案**：

- 确保dictUrl中使用了正确的占位符
- 检查接口地址是否正确
- 确保onlySearchDataWhenDependencesChange属性设置正确
- 检查依赖数据是否正确更新

### 问题4：多级依赖关系不工作

**解决方案**：

- 确保每一级的依赖关系都正确配置
- 确保上一级的变化能够正确触发下一级的更新
- 检查每一级的trigger函数是否正确更新了依赖数据

### 问题5：依赖字段的显示/隐藏不生效

**解决方案**：

- 确保使用了正确的visible属性配置
- 对于计算属性，确保计算逻辑正确
- 对于响应式数据，确保数据更新后UI能够正确响应
