# 开发文档

## 功能概述

本技能旨在为用户提供业务开发指导，帮助用户快速开发和优化业务功能模块。

## 适用场景

- 用户需要从头开发一个新的功能模块页面
- 用户需要添加、更改或优化现有页面模块的功能

## 工作流程

### 1. 需求类型识别

分析用户输入内容，判断需求类型：

- **新功能开发**：从头开发一个新的功能模块
- **功能修改**：添加、更改或优化现有页面功能

### 2. 新功能开发流程

#### 2.1 需求文档解析

- 分析用户提供的需求文档
- 提取功能菜单结构及对应功能页面
- 生成树形结构用于后续菜单mock数据

#### 2.2 模块页面开发

每个模块页面按以下流程生成代码：

**a. 主页面生成**

- 判断是使用useChcGrid还是useSpdGrid[useChcGrid还是useSpdGrid](reference/useChcGrid还是useSpdGrid.md)

- 根据需求选择主页面类型：这里需要根据上文决定页面是使用useChcGrid还是useSpdGrid构建表格
  - [带tab的主页面](reference/带tab的主页面.md)
  - [单个表格主页面](reference/单个表格主页面.md)
  - [父子表主页面](reference/父子表主页面.md)
  - [EditableTable可编辑表格](reference/editableTable.md) - 用于需要行内编辑的明细数据场景

**b. 页面配置完善**

- 表单配置：
  - [form item项定义](reference/表单配置-FormItem项定义.md)
  - [对应字段定义](reference/表单配置-字段定义.md)
  - [item项间依赖关系](reference/表单配置-依赖关系.md)
  - [自定义配置](reference/表单配置-自定义配置.md)
- 表格配置：
  - [column定义](reference/表格配置-Column定义.md)
  - [表格自定义配置](reference/表格配置-表格自定义配置.md)

**c. 功能按钮与逻辑分析**

- [判断是否需要添加新增按钮及逻辑](reference/功能按钮与逻辑分析-新增按钮.md)
- [判断是否需要添加导出功能](reference/功能按钮与逻辑分析-导出功能.md)
- [生成表格操作列功能按钮及对应逻辑](reference/功能按钮与逻辑分析-表格操作列.md)

**d. 新增功能实现** 提供三种新增功能实现方式：

- [新增弹窗模式](reference/新增功能实现-弹窗模式.md)
- [新增drawer模式](reference/新增功能实现-drawer模式.md)
- [新增页面模式](reference/新增功能实现-页面模式.md) 为每种方式提供基础的新增表单示例代码

**e. 编辑与查看功能** 参考新增功能的实现方式生成对应的编辑与查看功能代码

**f. API接口与mock数据生成** ：若用户要求生成api接口和mock数据，需要在需求文档中明确说明。若未要求生成api接口和mock数据，需要用户在后续开发中手动添加。

- [生成所有功能操作对应的API接口定义](reference/api.md)
- 生成配套的mock数据：[参考mock数据添加规范](./reference/mock.md)

### 3. 功能修改与优化流程

当用户需要添加、更改或优化原页面功能时：

#### 3.1 功能类型识别

- [表单依赖关系调整](reference/表单配置-依赖关系.md)
- [表格配置修改](reference/表格配置-表格自定义配置.md)
- [表单配置修改](reference/表单配置-自定义配置.md)
- [表格操作列按钮调整](reference/功能按钮与逻辑分析-表格操作列.md)

#### 3.2 代码修改建议

针对识别出的具体功能类型，提供相应的代码修改建议和实现指导

## 使用示例

### 示例1：新功能开发

**用户输入**：

> 我需要开发一个用户管理模块，包含用户列表页面和用户详情页面，用户列表页面需要支持搜索、新增、编辑、删除功能。

**技能响应**：

1. 分析需求，识别为新功能开发
2. 生成菜单结构：用户管理 -> 用户列表、用户详情
3. 生成用户列表主页面（单个表格主页面）
4. 完善表单配置（搜索表单）和表格配置
5. 生成新增、编辑、删除功能按钮及逻辑
6. 生成API接口和mock数据
7. 生成菜单mock数据

### 示例2：功能修改

**用户输入**：

> 我需要在现有的用户列表页面添加导出功能，并且优化搜索表单的依赖关系。

**技能响应**：

1. 分析需求，识别为功能修改
2. 识别具体功能类型：表格头部功能按钮修改（添加导出）和表单依赖关系调整
3. 提供相应的代码修改建议
4. 生成导出功能的API接口和mock数据

- Ant Design Vue组件库
- Vben组件

## 注意事项

- 请提供详细的需求文档，以便更准确地分析和生成代码
- 对于现有页面的修改，请提供相关的代码文件路径和具体修改需求
- 生成的代码为示例代码，需要根据实际项目结构进行调整
