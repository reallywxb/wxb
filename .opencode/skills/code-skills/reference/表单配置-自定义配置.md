# 表单配置-自定义配置

## 1. 概述

本文档详细介绍如何通过 `useChcGrid` 和 `useSpdGrid` 方法的第一个参数 `options.formOptions` 进行自定义表单配置。这些配置选项基于 `useVbenForm` 函数，提供了丰富的表单自定义能力。

## 2. useVbenForm 配置选项详解

### 2.1 核心配置选项

| 配置项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `schema` | `FormSchema[]` | `[]` | 表单字段定义数组 |
| `layout` | `'horizontal' \| 'vertical'` | `'horizontal'` | 表单布局方式 |
| `wrapperClass` | `string` | `'grid-cols-1'` | 表单栅格布局类 |
| `collapsed` | `boolean` | `false` | 是否展开，在 `showCollapseButton=true` 下生效 |
| `collapsedRows` | `number` | `1` | 折叠时保持的行数 |
| `showCollapseButton` | `boolean` | `false` | 是否显示展开/折叠按钮 |
| `commonConfig` | `FormCommonConfig` | `{}` | 表单项通用后备配置 |
| `compact` | `boolean` | `false` | 紧凑模式，移除表单每一项底部为校验信息预留的空间 |

### 2.2 FormCommonConfig 配置选项

| 配置项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `colon` | `boolean` | `false` | 在 Label 后显示一个冒号 |
| `componentProps` | `ComponentProps` | `{}` | 所有表单项的 props |
| `controlClass` | `string` | `''` | 所有表单项的控件样式 |
| `disabled` | `boolean` | `false` | 所有表单项的禁用状态 |
| `disabledOnChangeListener` | `boolean` | `true` | 是否禁用所有表单项的 change 事件监听 |
| `disabledOnInputListener` | `boolean` | `true` | 是否禁用所有表单项的 input 事件监听 |
| `emptyStateValue` | `null \| undefined` | `undefined` | 所有表单项的空状态值 |
| `formFieldProps` | `FormFieldOptions` | `{}` | 所有表单项的字段选项 |
| `formItemClass` | `string` | `''` | 所有表单项的栅格布局 |
| `hideLabel` | `boolean` | `false` | 隐藏所有表单项 label |
| `hideRequiredMark` | `boolean` | `false` | 是否隐藏必填标记 |
| `labelClass` | `string` | `''` | 所有表单项的 label 样式 |
| `labelWidth` | `number` | `undefined` | 所有表单项的 label 宽度 |
| `modelPropName` | `string` | `'modelValue'` | 所有表单项的 model 属性名 |
| `wrapperClass` | `string` | `''` | 所有表单项的 wrapper 样式 |

### 2.3 操作按钮配置

| 配置项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `showDefaultActions` | `boolean` | `true` | 是否显示默认操作按钮 |
| `actionButtonsReverse` | `boolean` | `false` | 操作按钮是否反转（提交按钮前置） |
| `actionWrapperClass` | `ClassType` | `''` | 表单操作区域 class |
| `submitButtonOptions` | `ActionButtonOptions` | `{}` | 提交按钮参数 |
| `resetButtonOptions` | `ActionButtonOptions` | `{}` | 重置按钮参数 |

### 2.4 回调函数

| 配置项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `handleSubmit` | `(values: Record<string, any>) => Promise<void> \| void` | `undefined` | 表单提交回调 |
| `handleReset` | `(values: Record<string, any>) => Promise<void> \| void` | `undefined` | 表单重置回调 |
| `handleValuesChange` | `(values: Record<string, any>, fieldsChanged: string[]) => void` | `undefined` | 表单值变化回调 |

### 2.5 其他配置

| 配置项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `id` | `string` | `undefined` | 表单 ID |
| `popupContainerClass` | `string` | `undefined` | 用于表单内的 popup 的容器类名 |
| `rangeFieldFromSuffix` | `string` | `undefined` | 范围查询字段参数起始值后缀 |
| `rangeFieldToSuffix` | `string` | `undefined` | 范围查询字段参数结束值后缀 |
| `submitOnChange` | `boolean` | `false` | 是否在字段值改变时提交表单 |
| `submitOnEnter` | `boolean` | `false` | 是否在回车时提交表单 |
| `arrayToStringFields` | `ArrayToStringFields` | `undefined` | 表单字段数组映射字符串配置 |
| `fieldMappingTime` | `FieldMappingTime` | `undefined` | 表单字段映射到时间格式 |
| `queryAdvSearchKeys` | `() => Promise<AdvSearchField[]>` | `undefined` | 高级查询字段获取方法，详细配置请参考 [表单配置-高级查询](表单配置-高级查询.md) |

## 3. 业务场景分析

### 3.1 基本表单配置

**场景**：设置表单的基本布局和样式

**配置示例**：

```javascript
const [ChcGrid] = useChcGrid(
  {
    formOptions: {
      layout: 'horizontal',
      wrapperClass: 'grid-cols-1 md:grid-cols-2 lg:grid-cols-3',
      commonConfig: {
        labelWidth: 100,
        labelClass: 'font-medium',
        controlClass: 'flex-1',
      },
    },
  },
  // 其他配置...
);
```

### 3.2 带折叠功能的表单

**场景**：当表单字段较多时，使用折叠功能优化页面空间

**配置示例**：

```javascript
const [ChcGrid] = useChcGrid(
  {
    formOptions: {
      showCollapseButton: true,
      collapsed: false,
      collapsedRows: 2,
    },
  },
  // 其他配置...
);
```

      },

        content: '重置',

### 3.4 表单值变化监听

**场景**：需要在表单值变化时执行特定逻辑

**配置示例**：

```javascript

        // 执行自定义逻辑

  // 其他配置...
);
```

### 3.5 紧凑模式表单

**场景**：在空间有限的情况下使用紧凑模式

## 5. 最佳实践

### 5.1 配置分离

**推荐做法**：将表单配置分离到单独的文件中，提高代码可维护性

**示例**：

```javascript
// formOptions.ts
export const searchFormOptions = {
  layout: 'horizontal',
  wrapperClass: 'grid-cols-1 md:grid-cols-2 lg:grid-cols-3',
  commonConfig: {
    labelWidth: 100,
    labelClass: 'font-medium',
  },
  showCollapseButton: true,
  collapsedRows: 2,
};

// 使用
import { searchFormOptions } from './formOptions';

const [ChcGrid] = useChcGrid(
  {
    formOptions: searchFormOptions,
  },
  // 其他配置...
);
```

### 5.2 深度合并默认配置

**推荐做法**：使用 `deepMerge` 合并默认配置和自定义配置，确保默认功能不丢失

**示例**：

```javascript
import { deepMerge } from '#/utils/util';
import { formDefaultOptions } from '#/components/spd/config/formDefaultOptions';

const [ChcGrid] = useChcGrid(
  {
    formOptions: deepMerge(formDefaultOptions, {
      layout: 'horizontal',
      wrapperClass: 'grid-cols-1 md:grid-cols-2',
    }),
  },
  // 其他配置...
);
```

### 5.3 响应式布局

**推荐做法**：使用 Tailwind CSS 的响应式类实现不同屏幕尺寸的适配

**示例**：

```javascript
const [ChcGrid] = useChcGrid(
  {
    formOptions: {
      wrapperClass: 'grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4',
    },
  },
  // 其他配置...
);
```

### 5.4 性能优化

**推荐做法**：对于大型表单，合理使用 `disabledOnChangeListener` 和 `disabledOnInputListener` 减少事件监听

**示例**：

```javascript
const [ChcGrid] = useChcGrid(
  {
    formOptions: {
      commonConfig: {
        disabledOnChangeListener: true,
        disabledOnInputListener: true,
      },
    },
  },
  // 其他配置...
);
```

## 6. 注意事项

1. **配置优先级**：子表单项的配置优先级高于 `commonConfig` 中的配置

2. **表单 ID 与 popupContainerClass**：当表单内有 select 等弹出组件时，建议使用 `popupContainerClass` 而不是 `id` 来指定容器类名，因为 `id` 属性未来可能有其他用途

3. **折叠功能**：`collapsed` 和 `collapsedRows` 配置仅在 `showCollapseButton=true` 时生效

4. **响应式布局**：使用 `wrapperClass` 配置响应式布局时，建议使用 Tailwind CSS 的栅格类

5. **性能考虑**：对于包含大量字段的表单，建议启用 `compact` 模式以减少 DOM 元素

## 7. 完整示例

### 7.1 useChcGrid 表单配置示例

```vue
<script lang="ts" setup>
import { useChcGrid } from '#/adapter/chc-ui';
import { deepMerge } from '#/utils/util';
import { formDefaultOptions } from '#/adapter/config/formDefaultOptions';

const [ChcGrid] = useChcGrid(
  {
    formOptions: deepMerge(formDefaultOptions, {
      layout: 'horizontal',
      wrapperClass: 'grid-cols-1 md:grid-cols-2 lg:grid-cols-3',
      commonConfig: {
        labelWidth: 100,
        labelClass: 'font-medium',
        controlClass: 'flex-1',
      },
      showCollapseButton: true,
      collapsed: false,
      collapsedRows: 2,
      submitButtonOptions: {
        content: '查询',
        type: 'primary',
      },
      resetButtonOptions: {
        content: '重置',
      },
      handleValuesChange: (values, fieldsChanged) => {
        console.log('Form values changed:', values);
      },
    }),
  },
  {
    gridColumns: [
      { field: 'index', title: '序号', type: 'seq', width: 50 },
      { field: 'name', title: '名称', minWidth: 120 },
      { field: 'code', title: '编码', minWidth: 100 },
      { field: 'description', title: '描述', minWidth: 150 },
      {
        field: 'action',
        title: '操作',
        width: 120,
        fixed: 'right',
        cellRender: {
          name: 'CustomCellMenu',
          options: ['view', 'edit', 'delete'],
        },
      },
    ],
    formSchema: [
      {
        component: 'Input',
        fieldName: 'name',
        label: '名称',
      },
      {
        component: 'Input',
        fieldName: 'code',
        label: '编码',
      },
      {
        component: 'Select',
        fieldName: 'status',
        label: '状态',
        componentProps: {
          options: [
            { label: '启用', value: 1 },
            { label: '禁用', value: 0 },
          ],
        },
      },
    ],
    id: 'example.table',
    dataTableId: 'example.table',
    showToolbar: true,
    showAddBtn: true,
    showExportBtn: true,
  },
);
</script>

<template>
  <div class="p-4">
    <ChcGrid />
  </div>
</template>
```

## 8. 总结

通过本文档的介绍，您应该已经了解了如何通过 `options.formOptions` 对 `useChcGrid` 和 `useSpdGrid` 中的表单进行自定义配置。这些配置选项提供了丰富的灵活性，可以满足各种业务场景的需求。

在实际使用中，建议根据具体的业务需求和用户体验要求，合理配置表单选项，以达到最佳的使用效果。同时，注意遵循本文档中提到的最佳实践和注意事项，确保代码的可维护性和性能。

如果您需要了解高级查询功能的详细配置方法，请参考 [表单配置-高级查询](表单配置-高级查询.md) 文档。
