# 单个表格主页面功能模块

## 功能模块概述与用途说明

单个表格主页面是一种以表格为核心的页面布局模式，用于展示和管理数据列表。它通常包含搜索表单、数据表格、操作按钮等元素，是业务系统中最常见的页面类型之一。

**主要用途**：

- 数据列表展示与管理
- 数据搜索与筛选
- 数据新增、编辑、删除操作
- 数据导出功能
- 数据详情查看

## 核心实现原理与架构设计

### 架构设计

单个表格主页面采用以下架构：

1. **Page组件**：作为页面容器，提供基础布局
2. **ChcGrid组件**：基于vxe-table封装的表格组件，提供完整的表格功能
3. **useChcGrid hook**：用于配置和生成表格
4. **表单配置**：定义搜索表单和新增/编辑表单
5. **表格配置**：定义表格列、操作按钮等

### 核心原理

1. **表格生成**：通过useChcGrid hook根据配置生成表格组件
2. **数据获取**：自动处理分页、排序、筛选等数据请求
3. **表单联动**：支持表单字段间的依赖关系
4. **操作处理**：统一处理新增、编辑、删除、查看等操作
5. **权限控制**：基于配置的权限信息控制操作按钮的显示

## 标准实现步骤与最佳实践

### 实现步骤

1. **导入依赖**：导入Page组件、useChcGrid hook等必要依赖
2. **定义状态变量**：定义表单依赖等状态变量
3. **配置表格选项**：
   - 定义表格列（gridColumns）
   - 定义搜索表单（formSchema）
   - 配置权限（permissions）
   - 配置操作按钮（showAddBtn, showExportBtn等）
   - 配置新增/编辑表单（commonFormOptions, viewFormOptions）
4. **生成表格组件**：使用useChcGrid生成表格组件
5. **处理自定义操作**：实现自定义操作的处理函数
6. **渲染页面**：在模板中使用Page组件和生成的表格组件

### 最佳实践

1. **配置分离**：将表单配置、表格配置等分离到单独的文件中，提高代码可维护性
2. **权限控制**：合理配置权限信息，确保操作安全性
3. **表单验证**：为新增/编辑表单添加适当的验证规则
4. **性能优化**：对于大数据量的表格，考虑使用虚拟滚动等优化手段
5. **用户体验**：添加适当的加载状态、操作反馈等

## 完整的代码示例

### 主页面示例

**说明**：示例代码中的表格组件统一使用的useChcGrid，实际使用请根据上文判断是使用useChcGrid还是useSpdGrid

```vue
<script lang="ts" setup>
import { ref } from 'vue';

import { Page } from '@vben/common-ui'; // 页面组件
import { useChcGrid } from '#/adapter/chc-ui'; // 导入生成表格的hook
import { $t } from '#/locales'; // 多语言

// 导入表单配置
import { addFormOptions, viewFormOptions } from './formOptions';

// 定义表单依赖
const deptIdDependencies = ref({ orgId: '' });

// 生成表格组件
const [ChcGrid, ChcGridApi] = useChcGrid(
  {
    formOptions: {
      commonConfig: {
        labelClass: 'w-[60px]',
      },
    },
  },
  {
    // 表格列配置
    gridColumns: [
      { field: 'index', fixed: 'left', title: '序号', type: 'seq', width: 50 },
      {
        field: 'id',
        minWidth: 100,
        sortable: true,
        title: '用户ID',
        key: true,
      },
      {
        title: '机构',
        field: 'orgId',
        formatter: (params: any) => {
          return params.row.orgId_name;
        },
        sortable: true,
        minWidth: 100,
      },
      {
        field: 'deptId',
        formatter: (params: any) => {
          return params.row.deptId_name;
        },
        minWidth: 100,
        sortable: true,
        title: '部门',
      },
      { field: 'name', minWidth: 100, sortable: true, title: '姓名' },
      { field: 'username', minWidth: 100, sortable: true, title: '登录名' },
      {
        align: 'center',
        cellRender: {
          attrs: {
            onClick: onActionClick,
          },
          name: 'CustomCellMenu',
          options: [
            'view',
            'edit',
            'delete',
            'log',
            {
              code: 'resetPassword',
              text: '重置密码',
            },
          ],
        },
        field: 'action',
        fixed: 'right',
        headerAlign: 'center',
        showOverflow: false,
        title: $t('system.menu.operation'),
        width: 256,
      },
    ],
    // 搜索表单配置
    formSchema: [
      {
        component: 'ChcSelect',
        componentProps: () => {
          return {
            dictUrl: '/sys/org/pageOrgList',
            showSearch: true,
            placeholder: '请选择',
            allowClear: true,
            paginate: true,
            filterByFrontEnd: false,
            showChooseAll: '',
            immediate: true,
          };
        },
        defaultValue: '',
        fieldName: 'orgId',
        label: '机构',
      },
      {
        component: 'ChcSelect',
        componentProps: () => {
          return {
            onlySearchDataWhenDependencesChange: true,
            placeholder: '请选择',
            paginate: false,
            showChooseAll: '',
            dictUrl: 'sys/dept/deptList/{{orgId}}',
            showSearch: true,
            triggerFields: ['orgId'],
            triggerFieldKeys: {
              orgId: 'orgId',
            },
            filterByFrontEnd: true,
            dependencies: deptIdDependencies.value,
            formatInterfaceData: (data: any) => {
              return { records: data };
            },
          };
        },
        dependencies: {
          triggerFields: ['orgId'],
          trigger(values: any) {
            deptIdDependencies.value.orgId = values.orgId;
            ChcGridApi.formApi?.setFieldValue?.('deptId', undefined);
          },
        },
        fieldName: 'deptId',
        label: '部门',
      },
      {
        component: 'Input',
        fieldName: 'name',
        label: '姓名',
      },
      {
        component: 'Input',
        fieldName: 'username',
        label: '登录名',
      },
    ],
    // 表格ID
    id: 'sys.user',
    // 权限配置
    permissions: {
      log: 'sys.user.delete',
      export: 'sys.user.delete',
    },
    dataTableId: 'sys.user',
    showToolbar: true,
    // 新增/编辑表单配置
    commonFormOptions: addFormOptions,
    // 查看表单配置
    viewFormOptions,
    showCellMenuIconBtn: false,
    // 显示新增按钮
    showAddBtn: true,
    // 显示导出按钮
    showExportBtn: true,
  },
);

// 处理自定义操作
function onActionClick({ code, row }: OnActionClickParams) {
  switch (code) {
    case 'resetPassword': {
      handleResetPassword(row);
      break;
    }
    default: {
      break;
    }
  }
}

// 重置密码处理
function handleResetPassword(row: any) {
  console.warn(row);
  // 实现重置密码逻辑
}
</script>

<template>
  <Page auto-content-height content-class="p-[0.5rem]" header-class="px-3 py-2">
    <ChcGrid />
  </Page>
</template>

<style scoped></style>
```

## 相关组件/API的使用说明

### useChcGrid hook

**参数**：

- `options`：表格选项配置
  - `formOptions`：表单配置
- `gridOptions`：表格配置
  - `gridColumns`：表格列配置
  - `formSchema`：搜索表单配置
  - `id`：表格ID
  - `permissions`：权限配置
  - `dataTableId`：数据表格ID
  - `showToolbar`：是否显示工具栏
  - `commonFormOptions`：新增/编辑表单配置
  - `viewFormOptions`：查看表单配置
  - `showAddBtn`：是否显示新增按钮
  - `showExportBtn`：是否显示导出按钮

**返回值**：

- `ChcGrid`：表格组件
- `ChcGridApi`：表格API，包含formApi等方法

### Page组件

**属性**：

- `auto-content-height`：自动计算内容高度
- `content-class`：内容区域样式类
- `header-class`：头部区域样式类

### 表格操作按钮

**内置操作**：

- `view`：查看
- `edit`：编辑
- `delete`：删除
- `log`：日志

**自定义操作**：

```typescript
{
  code: 'resetPassword',
  text: '重置密码',
}
```

## 常见问题与解决方案

### 问题1：表单依赖关系不生效

**解决方案**：

- 确保正确配置dependencies属性
- 使用trigger函数更新依赖值
- 对于ChcSelect组件，确保正确配置triggerFields和triggerFieldKeys

### 问题2：表格数据不显示

**解决方案**：

- 检查id和dataTableId配置是否正确
- 确保API接口返回正确的数据格式
- 检查权限配置是否正确

### 问题3：新增/编辑表单不显示

**解决方案**：

- 确保正确配置commonFormOptions和viewFormOptions
- 检查表单字段的component配置是否正确
- 确保表单依赖的字典数据能够正常获取

### 问题4：操作按钮权限控制不生效

**解决方案**：

- 确保正确配置permissions属性
- 检查用户是否具有相应的权限
- 检查权限系统是否正常工作
