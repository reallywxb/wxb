# 表单配置-高级查询

## 1. 高级查询功能的实现逻辑

### 1.1 核心实现原理

高级查询功能通过以下几个核心组件和方法实现：

1. **AdvSearchField 类型定义**：在 `packages\@core\ui-kit\form-ui\src\types.ts` 中定义了高级查询字段的类型结构
2. **AdvancedSearch 组件**：在 `packages\@core\ui-kit\form-ui\src\form-render\advancedSearch.vue` 中实现了高级查询的UI界面
3. **getAdvSearchKeysFn 方法**：在 `apps\newrepo\src\api\core\auth.ts` 中实现了获取高级查询字段的方法
4. **表单集成**：在 `packages\@core\ui-kit\form-ui\src\vben-use-form.vue` 中集成了高级查询功能

### 1.2 实现流程

1. **配置高级查询字段**：通过 `queryAdvSearchKeys` 配置项指定获取高级查询字段的方法
2. **加载字段数据**：表单初始化时调用 `queryAdvSearchKeys` 方法获取高级查询字段列表
3. **构建查询条件**：用户在高级查询界面添加查询条件，选择字段、运算符和值
4. **生成查询参数**：根据用户选择的条件生成查询参数
5. **执行查询**：将查询参数传递给表格的查询方法

### 1.3 关键代码实现

#### 1.3.1 高级查询字段类型定义

#### 1.3.2 getAdvSearchKeysFn 方法实现

```typescript
// apps\newrepo\src\api\core\auth.ts
export function getAdvSearchKeysFn(
  menuPageId: string,
): () => Promise<AdvSearchField[]> {
  return () => {
    return new Promise<AdvSearchField[]>((resolve) => {
      requestFormClient
        .get('/auth/advSearchKeys', {
          params: {
            menuPageId,
          },
        })
        .then((res) => {
          if (res.success) {
            resolve(res.data);
          } else {
            resolve([]);
          }
        })
        .catch(() => {
          resolve([]);
        });
    });
  };
}
```

#### 1.3.3 表单集成高级查询

```typescript
// packages\@core\ui-kit\form-ui\src\vben-use-form.vue
const advSearchItems = ref<AdvSearchItem[]>([]);

const getAdvancedSearchValues = () => {
  const conditions = advSearchItems.value
    .filter((item) => item.field && item.operator)
    .map((item) => {
      return {
        field: item.field,
        operator: item.operator,
        value: item.value,
      };
    });
  return {
    conditions,
  };
};
props.formApi.updateAdvancedSearchValuesFn(getAdvancedSearchValues);
const advSearchFields = ref<AdvSearchField[]>([]);
const showOuterAdvSearch = ref(true);
const toggleShowOuterAdvSearch = () => {
  showOuterAdvSearch.value = !showOuterAdvSearch.value;
};
unref(forward).queryAdvSearchKeys &&
  unref(forward).queryAdvSearchKeys!().then((res) => {
    advSearchFields.value = res;
  });
```

## 2. 如何在页面添加高级查询功能

### 2.1 基本配置步骤

1. **导入 getAdvSearchKeysFn 方法**：

   ```typescript
   import { getAdvSearchKeysFn } from '#/api';
   ```

2. **在表单配置中添加 queryAdvSearchKeys**：

   ```typescript
   formOptions: {
     // 其他配置...
     queryAdvSearchKeys: getAdvSearchKeysFn('menuPageId'),
     // 其他配置...
   }
   ```

3. **menuPageId 参数说明**：
   - 对于仓库产品页面，使用接口地址作为 menuPageId：`/warehouseAction/queryWarehouseProduct.do`
   - 对于其他页面，使用对应的菜单页面ID

### 2.2 完整示例

```typescript
import { getAdvSearchKeysFn } from '#/api';
import { formDefaultOptions, useSpdGrid } from '#/components/spd';
import { deepMerge } from '#/utils/util';

const [ChcGrid, ChcGridApi] = useSpdGrid(
  {
    formOptions: deepMerge(formDefaultOptions, {
      // 其他配置...
      queryAdvSearchKeys: getAdvSearchKeysFn(
        '/warehouseAction/queryWarehouseProduct.do',
      ),
      // 其他配置...
    }),
    // 其他配置...
  },
  {
    // 表格配置...
  },
);
```

## 3. ChcSelect 组件的配置项

### 3.1 itemProps 字段说明

在高级查询中，`AdvSearchField` 的 `itemProps` 字段会作为 ChcSelect 组件的配置对象。以下是 ChcSelect 组件支持的所有配置项：

### 3.2 配置项列表

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| afterFetch | Function | undefined | 用于获取到接口数据后的处理方法 |
| allowClear | boolean | true | 是否可以清除输入 |
| apiType | string | 'get' | 接口模式 get / post |
| autoChooseFirstOption | boolean | false | 是否自动选择下拉数据的第一项 |
| beforeFetch | Function | undefined | 用于获取接口数据前处理params的方法 |
| blackList | any[] | undefined | 黑名单，在黑名单上的项将不可选 |
| chooseAllLabel | string | '全选' | 全选项的label |
| dependencies | Object | undefined | 依赖数据对象 |
| dictUrl | string | '' | 动态查询接口路径 |
| extraParams | Object/Function | undefined | 接口额外字段 |
| filterByFrontEnd | boolean | true | 是否前端过滤 |
| filterField | string | 'query' | showSearch过滤打开的场景下传递查询文本的接口字段 |
| formatInterfaceData | Function | undefined | 用于格式化接口数据的方法 |
| handleParams | Function | undefined | 预处理接口字段 |
| immediate | boolean | true | 是否立即调用接口获取下拉数据 |
| labelField | string | 'label' | 指定label对应的key |
| onLoad | Function | undefined | Option数据加载完毕回调 |
| onlySearchDataWhenDependencesChange | boolean | false | 仅在依赖项变化时，由用户主动触发fetchApi方法，才会查询下拉数据 |
| optionColumns | Array | [] | 用于展示下拉表格的配置 |
| options | Array | [] | 直接传入选项数据，不走接口 |
| pageSize | number | 20 | 下拉分页每页数量 |
| paginate | boolean | false | 下拉是否展示分页 |
| paramsMap | Object | {} | 用于映射params内参数 |
| queryDataApi | Function | undefined | 自定义查询接口 |
| refreshOptionsWhenOpenDropdown | boolean | false | 仅在下拉框拉起时调用接口查数据 |
| requestConfig | Object | undefined | 自定义接口配置参数 |
| requestContentType | string | 'application/json' | 查询请求的接口Content-Type |
| showChooseAll | boolean/number/string | undefined | 是否展示全选项 |
| showSearch | boolean | false | 是否能筛选 |
| triggerFieldKeys | Object | {} | 指定依赖项对应到接口的字段 |
| triggerFields | Array | [] | 指定依赖字段，form内该字段变化，会触发本组件更新 |
| valueField | string | 'value' | 指定value对应的key |

## 5. 总结

高级查询功能是表单的重要组成部分，通过以下方式实现：

1. **配置简单**：只需在表单配置中添加 `queryAdvSearchKeys` 配置项，指定获取高级查询字段的方法
2. **灵活定制**：通过 `itemProps` 字段可以为 ChcSelect 组件提供丰富的配置选项
3. **用户友好**：提供了直观的界面，允许用户添加、删除和配置查询条件
4. **功能完整**：支持多种数据类型和运算符，满足复杂的查询需求

通过合理配置高级查询功能，可以大大提高用户的查询效率和体验。
