# 父子表主页面功能模块

## 功能模块概述与用途说明

父子表主页面是一种展示主从关系数据的页面布局模式，通过分割面板展示主表和子表，实现数据的层级展示和关联操作。它通常用于展示具有一对多关系的数据，如用户与角色、订单与订单详情等。

**主要用途**：

- 展示主从关系数据
- 实现主表选择后自动刷新子表数据
- 提供统一的操作界面
- 提高数据关联的可视化程度

## 核心实现原理与架构设计

### 架构设计

父子表主页面采用以下架构：

1. **Page组件**：作为页面容器，提供基础布局
2. **PageSplitLazy组件**：实现页面分割，用于展示主表和子表
3. **ChcGrid组件**：基于vxe-table封装的表格组件，用于展示数据
4. **useChcGrid hook**：用于配置和生成表格
5. **Tabs组件**：用于在子表区域展示多个子表格
6. **状态管理**：通过ref和props传递实现主表与子表的数据关联

### 核心原理

1. **页面分割**：使用PageSplitLazy组件将页面分为左右或上下两部分
2. **主表选择**：监听主表的选择事件，获取当前选中行数据
3. **子表联动**：将主表选中行的关键信息传递给子表，子表根据该信息刷新数据
4. **多子表管理**：使用Tabs组件管理多个子表，实现子表间的切换

## 标准实现步骤与最佳实践

### 实现步骤

1. **导入依赖**：导入Page、PageSplitLazy、Tabs等组件，以及useChcGrid hook
2. **定义状态变量**：定义parentRow等状态变量，用于存储主表选中行数据
3. **配置主表**：使用useChcGrid配置主表，监听radioChange事件
4. **配置子表**：使用useChcGrid配置各个子表，接收parentRow作为参数
5. **实现行选择逻辑**：在主表的radioChange事件中更新parentRow
6. **渲染页面**：使用PageSplitLazy分割页面，左侧显示主表，右侧显示Tabs和子表

### 最佳实践

1. **数据传递**：使用响应式数据（ref）传递主表选中行信息，确保子表能及时响应
2. **性能优化**：对于子表数据，只在主表选择变化时才刷新，避免不必要的请求
3. **用户体验**：添加适当的加载状态和空数据提示
4. **代码组织**：将各个表格的配置分离到单独的文件中，提高代码可维护性
5. **错误处理**：添加适当的错误处理逻辑，确保页面在数据加载失败时仍能正常显示

## 完整的代码示例

### 主页面示例

**说明**：示例代码中的表格组件统一使用的useChcGrid，实际使用请根据上文判断是使用useChcGrid还是useSpdGrid

```vue
<script lang="ts" setup>
import { ref } from 'vue';

import { Page } from '@vben/common-ui'; // 页面组件
import { PageSplitLazy } from '@xgsk/vue3-page-split';
import { TabPane, Tabs } from 'ant-design-vue';
import { useChcGrid } from '#/adapter/chc-ui'; // 导入生成表格的hook

// 导入子表格配置
import {
  useUserOrgGridOptions,
  useUserRoleGridOptions,
  useUserTenantGridOptions,
} from './childOption';
import { useGridOptions } from './option';

// 存储主表选中行数据
const parentRow = ref({ userId: '' });

// 配置主表
const [ChcGrid] = useChcGrid(
  {
    gridEvents: {
      radioChange({ row }: { row: any }) {
        handleRowChange(row);
      },
    },
  },
  useGridOptions((actionCode: string) => {
    return {}[actionCode];
  }),
);

// 处理主表行选择
const handleRowChange = (row: any) => {
  parentRow.value.userId = row ? row.id : '';
};

// 配置子表：用户角色
const [UserRoleGrid] = useChcGrid(
  {},
  useUserRoleGridOptions((actionCode: string) => {
    return {}[actionCode];
  }, parentRow),
);

// 配置子表：用户机构
const [UserOrgGrid] = useChcGrid(
  {},
  useUserOrgGridOptions((actionCode: string) => {
    return {}[actionCode];
  }, parentRow),
);

// 配置子表：用户授权租户
const [UserTenantGrid] = useChcGrid(
  {},
  useUserTenantGridOptions((actionCode: string) => {
    return {}[actionCode];
  }, parentRow),
);
</script>

<template>
  <Page content-class="p-[0.5rem]" auto-content-height header-class="px-3 py-2">
    <PageSplitLazy
      :distribute="0.5"
      :line-thickness="6"
      :is-vertical="false"
      background-color="#f1f3f6"
      hover-color="#c0c4cc"
      :has-line-tip="true"
    >
      <!-- 左侧主表 -->
      <template #first>
        <ChcGrid />
      </template>
      <!-- 右侧子表 -->
      <template #second>
        <Tabs class="tabs h-full">
          <TabPane key="UserRole" tab="用户角色" class="tab-pane h-full">
            <UserRoleGrid />
          </TabPane>
          <TabPane
            key="UserOrg"
            tab="用户机构"
            class="tab-pane h-full"
            force-render
          >
            <UserOrgGrid />
          </TabPane>
          <TabPane
            key="UserTenant"
            tab="用户授权租户"
            class="tab-pane h-full"
            force-render
          >
            <UserTenantGrid />
          </TabPane>
        </Tabs>
      </template>
    </PageSplitLazy>
  </Page>
</template>

<style scoped>
::v-deep(.ant-tabs-content) {
  height: 100%;
}

::v-deep(.ant-tabs) {
  background-color: hsl(var(--background));
}

::v-deep(.ant-tabs-nav-wrap) {
  padding-left: 10px;
}
</style>
```

## 相关组件/API的使用说明

### PageSplitLazy组件

**属性**：

- `distribute`：分割比例，0-1之间的数值
- `line-thickness`：分割线厚度
- `is-vertical`：是否垂直分割
- `background-color`：分割线背景色
- `hover-color`：分割线 hover 颜色
- `has-line-tip`：是否显示分割线提示

**插槽**：

- `first`：左侧/上侧内容
- `second`：右侧/下侧内容

### Tabs组件

**属性**：

- `class`：样式类

**TabPane属性**：

- `key`：标签页key
- `tab`：标签页标题
- `class`：样式类
- `force-render`：是否强制渲染

### useChcGrid hook（子表配置）

**特殊配置**：

- `queryParams`：查询参数，可使用函数返回动态值
  ```typescript
  queryParams: {
    userId: () => parentRow.value.userId,
  }
  ```
- `showToolbar`：是否显示工具栏，子表通常设置为false
- `showAddBtn`：是否显示新增按钮，子表通常设置为false
- `showExportBtn`：是否显示导出按钮，子表通常设置为false

## 常见问题与解决方案

### 问题1：子表数据不随主表选择更新

**解决方案**：

- 确保parentRow是响应式的（使用ref）
- 确保子表的queryParams配置正确，使用函数返回parentRow的值
- 检查子表的API接口是否正确接收并处理userId参数

### 问题2：页面分割比例不合适

**解决方案**：

- 调整PageSplitLazy的distribute属性
- 根据实际数据量和页面大小设置合适的比例

### 问题3：子表标签页切换时数据丢失

**解决方案**：

- 为TabPane添加force-render属性，强制渲染所有子表
- 或在标签页切换时重新加载数据

### 问题4：主表未选择时子表显示错误

**解决方案**：

- 在子表配置中添加空数据处理
- 当parentRow.userId为空时，不发起数据请求

## 代码优化建议

1. **类型定义**：为parentRow和表格配置添加TypeScript类型定义
2. **状态管理**：对于复杂的父子表关系，考虑使用Pinia进行状态管理
3. **代码复用**：提取通用的子表配置逻辑，减少代码重复
4. **性能优化**：使用computed属性缓存计算结果，减少不必要的重渲染
5. **错误处理**：添加适当的错误处理逻辑，确保页面在数据加载失败时仍能正常显示
6. **用户体验**：添加加载状态、空数据提示等，提高用户体验
7. **可维护性**：添加适当的注释说明，提高代码可维护性
