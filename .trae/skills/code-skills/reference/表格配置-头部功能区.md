# 表格配置-头部功能区

## 概述

表格头部功能区是表格组件的重要组成部分，用于提供各种操作按钮和工具。通过useChcGrid生成的Grid组件支持多种方式配置头部功能区，包括：

- 通过toolbar-actions插槽自定义头部左侧按钮区
- 通过toolbar-tools插槽自定义头部右侧按钮区
- 通过showZoomBtn和showCustomBtn属性一键添加表格通用功能

## useChcGrid的配置方法

useChcGrid是对系统原有的useVbenVxeGrid做二次封装，将通用功能集成进来的方法。其基本使用方式如下：

```typescript
import { useChcGrid } from '#/adapter/chc-ui';
import { useGridOptions } from './option';

const [
  ChcGrid,
  ChcGridApi,
  { FormModal, handleAdd, handleEdit, handleDel, handleExport },
] = useChcGrid(
  {},
  useGridOptions((actionCode: string) => {
    return { edit: handleEdit, view: handleView, delete: handleDel }[
      actionCode
    ];
  }),
);
```

## toolbar-actions（头部左侧按钮区）的自定义配置

通过`toolbar-actions`插槽可以自定义表格头部左侧的按钮区域。示例如下：

```vue
<ChcGrid>
  <template #toolbar-actions>
    <Button
      type="primary"
      @click="handleExport"
      class="mr-[0.5rem]"
    >
      导 出
      <template #icon>
        <ExportActionIcon />
      </template>
    </Button>
    <Button
      type="primary"
      @click="handleSubmit"
      class="mr-[0.5rem]"
    >
      提 交
      <template #icon>
        <UploadCloudIcon />
      </template>
    </Button>
  </template>
</ChcGrid>
```

## toolbar-tools（头部右侧按钮区）的自定义配置

通过`toolbar-tools`插槽可以自定义表格头部右侧的工具区域。示例如下：

```vue
<ChcGrid>
  <template #toolbar-tools>
    <span style="margin-left: 20px">总金额：{{ totalAmount }}元</span>
    <Summarize ref="summarizeRef" />
  </template>
</ChcGrid>
```

## showZoomBtn和showCustomBtn属性的使用

通过在gridOptions中设置`showZoomBtn`和`showCustomBtn`属性，可以一键添加表格的通用功能：

- `showZoomBtn`：显示表格缩放按钮
- `showCustomBtn`：显示表格自定义按钮

配置示例：

```typescript
// 在useGridOptions中的配置
const useGridOptions = () => {
  return {
    // 其他配置...
    showCustomBtn: true, // 显示自定义按钮
    showZoomBtn: true, // 显示缩放按钮
    // 其他配置...
  };
};
```

## 实现原理

在`useChcGrid`的实现中，头部功能区的配置主要通过以下方式实现：

1. **默认按钮**：根据配置自动生成新增、导出等默认按钮
2. **插槽机制**：通过`toolbar-actions`和`toolbar-tools`插槽允许用户自定义按钮和工具
3. **属性配置**：通过`showZoomBtn`和`showCustomBtn`属性一键添加通用功能

核心实现代码：

```typescript
// 头部左侧按钮区
'toolbar-actions': () =>
  h('div', {}, [
    schemaColumnAndOptions.showAddBtn &&
    hasBtnAccess('add')
      ? h(Button, {
          type: 'primary',
          onClick: () => {
            handleAdd();
          },
          class: 'mr-[10px]',
          'data-testid': `addBtn_${getTableId()}`,
          disabled: depBtnDisabled.value,
        }, {
          default: () => '新增',
          icon: () =>
            h(AntdPlusCircleTwotone, {
              style: {
                marginBottom: '4px',
              },
            }),
        })
      : null,
    schemaColumnAndOptions.showExportBtn &&
    hasBtnAccess('export')
      ? h(Button, {
          type: 'primary',
          onClick: () => {
            handleExport();
          },
          class: 'mr-[0.75rem]',
          'data-testid': `exportBtn_${getTableId()}`,
          disabled: depBtnDisabled.value,
        }, {
          default: () => '导出',
          icon: () =>
            h(ExportActionIcon, {
              style: {
                marginBottom: '2px',
              },
            }),
        })
      : null,
  ].filter(Boolean),

// 头部右侧工具区
'toolbar-tools': (scope: any) =>
  slots['toolbar-tools']?.(scope),
```

## 总结

通过useChcGrid生成的Grid组件提供了灵活的表格头部功能区配置方式：

1. **自定义按钮**：通过`toolbar-actions`插槽可以添加任意自定义按钮
2. **自定义工具**：通过`toolbar-tools`插槽可以添加任意自定义工具
3. **通用功能**：通过`showZoomBtn`和`showCustomBtn`属性可以一键添加表格通用功能

这些配置方式可以根据具体业务需求灵活组合使用，为表格提供丰富的操作功能。
