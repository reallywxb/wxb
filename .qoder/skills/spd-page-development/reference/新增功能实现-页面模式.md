# 新增功能实现 - 页面模式

## 功能模块概述

页面模式是一种通过跳转到新页面来实现新增功能的方式。它为用户提供了完整的页面空间来填写表单，适合处理复杂的、多步骤的新增操作。

### 应用场景

- 新增表单非常复杂，包含多个步骤或多个部分
- 需要在新增过程中展示大量辅助信息或参考数据
- 新增操作需要与其他页面进行交互
- 希望提供独立的、沉浸式的新增体验
- 移动端设备上的复杂新增操作

### 业务价值

- 提供完整的页面空间，适合复杂表单
- 支持多步骤、向导式的新增流程
- 可以包含更多的辅助信息和参考数据
- 独立的页面上下文，减少干扰
- 更好的SEO优化和页面分享能力

## 核心实现原理

### 技术架构

- 基于Vue Router的路由导航
- 结合Vben框架的Form组件实现表单功能
- 使用ref和reactive管理表单状态
- 利用computed计算属性处理表单状态
- 通过路由参数传递数据
- 使用localStorage或sessionStorage存储临时数据

### 数据流程

1. 用户点击主页面的新增按钮，触发路由跳转
2. 跳转到新增页面，初始化表单数据
3. 用户填写表单数据，可能涉及多个步骤
4. 点击提交按钮，触发表单验证
5. 验证通过后，调用API提交数据
6. 提交成功后，跳转回主页面并刷新数据
7. 提交失败后，显示错误信息

### 关键算法

- 表单验证算法：使用Vben的Form组件内置验证规则
- 数据提交算法：封装API调用，处理成功/失败回调
- 状态管理算法：使用ref和computed管理表单状态
- 路由导航算法：使用Vue Router进行页面跳转和参数传递

## 标准实现步骤

### 前置条件与环境要求

- 项目已配置Vue Router
- 项目已集成Vben框架的Form组件
- 已配置好API接口
- 已创建好主页面和新增页面的路由

### 实现步骤

1. **配置路由**

   - 在Vue Router中添加新增页面的路由配置
   - 配置路由参数传递方式

2. **创建新增页面**

   - 创建新增页面组件
   - 设计页面布局和表单结构

3. **初始化表单数据**

   - 使用ref或reactive定义表单数据
   - 设置默认值和初始状态

4. **构建表单结构**

   - 使用Vben的Form组件构建表单
   - 定义表单项和验证规则

5. **实现提交逻辑**

   - 编写提交按钮的点击事件处理函数
   - 实现表单验证和API调用

6. **处理路由导航**

   - 实现提交成功后的路由跳转
   - 实现取消按钮的路由跳转

7. **添加页面状态管理**
   - 使用localStorage或sessionStorage存储临时数据
   - 实现页面刷新后的数据恢复

## 组件/API说明

### 核心组件

#### 1. useRouter

- **类型**: 函数
- **说明**: Vue Router的组合式API，用于获取路由实例
- **返回值**: 路由实例对象
- **主要方法**:
  - `push(location)`: 跳转到指定路由
  - `replace(location)`: 替换当前路由
  - `go(n)`: 前进或后退n步

#### 2. BasicForm

- **类型**: 组件
- **说明**: Vben框架的基础表单组件，用于快速构建表单
- **主要属性**:
  - `model`: 表单数据对象
  - `schema`: 表单配置 schema
  - `show-action-button-group`: 是否显示默认操作按钮组，默认true
- **事件**:
  - `submit`: 表单提交时触发

#### 3. PageHeader

- **类型**: 组件
- **说明**: Vben框架的页面头部组件，用于显示页面标题和操作
- **主要属性**:
  - `title`: 页面标题
  - `ghost`: 是否透明背景，默认true

#### 4. a-steps / a-step

- **类型**: 组件
- **说明**: Ant Design Vue的步骤条组件，用于显示多步骤流程
- **主要属性**:
  - `current`: 当前步骤索引
  - `title`: 步骤标题

### 工具函数

#### 1. ref

- **类型**: 函数
- **说明**: Vue 3的响应式API，用于创建响应式引用
- **参数**: 初始值
- **返回值**: 响应式引用对象

#### 2. reactive

- **类型**: 函数
- **说明**: Vue 3的响应式API，用于创建响应式对象
- **参数**: 普通对象
- **返回值**: 响应式对象

#### 3. computed

- **类型**: 函数
- **说明**: Vue 3的响应式API，用于创建计算属性
- **参数**: 计算函数
- **返回值**: 计算属性对象

## 常见问题与解决方案

### 1. 页面刷新后表单数据丢失

**问题**: 页面刷新后，表单数据丢失 **解决方案**: 使用localStorage或sessionStorage存储临时数据

```javascript
// 保存表单数据
const saveFormData = () => {
  sessionStorage.setItem('formData', JSON.stringify(formData));
};

// 加载表单数据
const loadFormData = () => {
  const savedData = sessionStorage.getItem('formData');
  if (savedData) {
    Object.assign(formData, JSON.parse(savedData));
  }
};

// 在组件挂载时加载数据
onMounted(() => {
  loadFormData();
});

// 在表单数据变化时保存
watch(formData, saveFormData, { deep: true });
```

### 2. 多步骤表单数据验证

**问题**: 多步骤表单中，如何验证当前步骤的表单数据 **解决方案**: 在切换步骤时进行验证

```javascript
// 下一步
const nextStep = async () => {
  if (currentStep.value === 0) {
    // 验证基本信息
    const valid = await formRef.value?.validate();
    if (!valid) return;
  }
  currentStep.value++;
};
```

### 3. 路由参数传递

**问题**: 如何在路由跳转时传递参数 **解决方案**: 使用路由参数或查询参数

```javascript
// 使用路径参数
router.push(`/edit/${record.id}`);

// 使用查询参数
router.push({
  path: '/add',
  query: { type: 'quick' },
});

// 在目标页面获取参数
import { useRoute } from 'vue-router';

const route = useRoute();
const id = route.params.id;
const type = route.query.type;
```

### 4. 页面权限控制

**问题**: 如何控制新增页面的访问权限 **解决方案**: 使用路由守卫

```javascript
// 在路由配置中添加权限控制
const routes = [
  {
    path: '/add',
    component: AddPage,
    meta: {
      requiresAuth: true,
      roles: ['admin', 'editor'],
    },
  },
];

// 添加路由守卫
router.beforeEach((to, from, next) => {
  if (to.meta.requiresAuth) {
    // 检查是否登录
    const isLoggedIn = localStorage.getItem('token');
    if (!isLoggedIn) {
      next('/login');
      return;
    }

    // 检查权限
    const userRole = localStorage.getItem('role');
    if (to.meta.roles && !to.meta.roles.includes(userRole)) {
      next('/403');
      return;
    }
  }
  next();
});
```

### 5. 表单提交后跳转到错误页面

**问题**: 表单提交后，由于网络问题或其他原因，跳转到错误页面 **解决方案**: 添加错误处理和重定向逻辑

## 最佳实践

1. **合理设计页面布局**: 根据表单复杂度，设计合适的页面布局
2. **使用多步骤表单**: 对于复杂表单，使用多步骤表单提高用户体验
3. **添加表单验证**: 充分利用Vben的表单验证功能，确保数据合法性
4. **实现数据持久化**: 使用localStorage或sessionStorage存储临时数据，防止页面刷新后数据丢失
5. **添加加载状态**: 在提交表单时，显示加载状态，提升用户体验
6. **完善错误处理**: 提供清晰的错误提示和处理机制
7. **优化路由导航**: 使用Vue Router的导航守卫，实现权限控制和页面跳转
8. **响应式设计**: 确保页面在不同设备上都能正常显示
